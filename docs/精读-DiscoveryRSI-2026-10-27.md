> 精读日期：2026-10-27。定位：**第十一章"出题困境"至今最完整的工程回答 + 11.5 节"结构裁判"的现成实现**。

## 0. 一句话读懂这篇论文

**让 agent 在"提出假设→修订假设→编译成可执行调查"的过程中留下完整档案，再用这些档案反过来训练模型和改进工作流——循环往复，使"做研究"本身变成一个可学习的过程。**

它和 AI Scientist 系列的根本区别：AI Scientist 优化"产出一篇论文"，DiscoveryRSI 优化"下一轮研究比这一轮做得好"。产物不是论文，是**被评估过的研究经验**。

## 1. 最大的概念贡献：假设的可操作定义（Definition 1）

一个有价值和可检验的研究假设被定义为四元组 **H = (c, π, d, a)**：

| 组件 | 含义 | 回答的问题 |
|---|---|---|
| **c** — claim | 有证据支撑的主张（指明系统/人群、范围、可观测量、科学不确定性） | 我们主张什么？ |
| **π** — investigation plan | 调查计划（数据/测量、对照、分析、依赖） | 怎么查？ |
| **d** — decision criteria | **在解读结果之前**就写明：什么结果支持主张、什么削弱、什么算无结论 | 出什么结果算赢/输/平？ |
| **a** — alternative explanations | 竞争解释、混杂、测量局限，以及能区分它们的比较 | 还有什么别的解释？怎么排除？ |

**"有价值"的定义**：解决 c 中的不确定性，能对现有理解做出重要补充，或改变一个有依据的研究决策。
**"可检验"的定义**：π 在声明的约束 B 内可行，且其可观测量经 d 和 a 解读后，能支持/削弱/约束 c。

**为什么这个定义重要**（对应调研报告 11.5 节）：
- 它把"价值"从整体拆成了可判定的组件——这正是我们说的"结构裁判"；
- 论文自己在 2.1 节就声明：这些要求评估的是**提出的研究机会**，不确立主张为真——诚实地区分了"假设质量"与"假设真值"；
- d 组件（预先声明判定标准）直接封死了"事后编故事"的空间——这是防 Goodhart 的结构化手段。

论文给出的实例（Figure 3，MIMIC-IV）值得逐字读：研究问题"反复的肌酐-尿量错配是否预测 ICU 出院后 48h 内不良结局"，配套 B0→B2→L1 三级基线（临床基线→当前错配→反复错配→HMM 摘要）、同一患者级切分、以及预先写好的支持/削弱/无结论判据和五条备择解释。**这就是一个"结构完整"的假设长什么样。**

## 2. 系统架构：三层循环

### 2.1 Episode 内：多智能体假设开发

- 角色：**Lead**（选方向、选父节点、选操作）+ **Generation / Evolution**（查证据、发布提案/修订）+ **Blinded Critique**（盲评科学价值）+ **Progress**（** ancestor-aware**：相对真实前驱判断是否有实质进展/必要修复/重复/证据不足）。
- 操作四种：**evolve**（发展假设）、**repair**（修复缺陷）、**crossover**（合并多个父节点的贡献）、**restart**（开新问题、不认父节点）。
- 假设树实际是 **DAG**（crossover 有多父），与 agent 的动作序列严格分开记录——这是后面 credit 分配能做对的前提。

### 2.2 编译：Harbor Task（假设 → 可执行调查）

选中的计算型调查编译成 Harbor 任务：具体输入、环境、要求输出、**验证检查**。
关键原则：**执行检查管"任务是否满足计算契约"，科学评估管"这个调查能确立什么"——两者严格分离。**
不可获得的数据/物理实验保持为**显式依赖**，而不是被静默跳过。
另一个要点：**假设开发本身就能产出学习经验，不需要等完整调查执行完**（3.2 节）——这让学习循环的周转不卡在实验上。

### 2.3 RSI 循环：三个学习机制（论文核心）

**① Hypothesis credit optimization（模型权重更新）**

三步链条：科学评估 → 假设 credit → 贡献者 credit → 训练目标。

- 盲评（Blinded Critique）给出偏好对/平局/弃权，用 **TrueSkill** 汇总成 (μ_h, σ_h)——论文明确说这是"比较性评估，**不是**假设为真的概率"；
- 贡献记录把 credit 分给**具体的调用历史**（history = 一次具体调用，不是某角色的全部工作）；公式 w_i = min(W_max, Σ_h b_ih) 有**上限截断**；
- 三条反作弊规则：无支持的份额不分配；**只凭血缘/参与不加 credit**；重复贡献被抑制 + 科学家族预算上限；
- 训练时 loss 只落在**被记录贡献支持的 assistant 动作**上（公式 4），工具观察和已知失败动作只做上下文、**不直接计 loss**。

**② Harness replay（工作流更新，模型冻结）**

- 短诊断跑暴露四类反复出现的失败：**重复探索、工具调用失败、工件丢失、过早关闭**；
- 把 agent 贡献/决策记录与执行/交付记录 join 起来定位问题 → 定点改工作流 → 在 dev set 上与现任 harness 对比验收（公式 5），现任始终保留参选资格；
- 注意：底座用的是成熟的 Codex / Claude Code harness，"协调、证据访问、评审时机、工作分配"才是他们改的层。

**③ Rediscovery（应用更新、回到新问题）**

- (θ_{k+1}, ψ_{k+1}) = Accept_dev({θ_k, θ_k⁺} × {ψ_k, ψ_k⁺})——模型、harness、两者、都不，四种可能分别独立验收；
- **开发族与最终评测族严格分离**（Algorithm 1 里 Q_dev / Q_test 分列，test 只在第 14 行碰一次）——防自我改进污染评测；
- "Scientific restart 改变一个 run 内的方向；rediscovery 改变下一个 run 的系统"——概念分工清晰。

**Algorithm 1 全貌**（伪代码 15 行，强烈建议照抄结构）：研究 → 选编译 → 评估 → credit 分配 → 加权训练 → harness 提案 → dev 验收 → 进入下一轮。

## 3. DFM-Bench：把"研究过程"整体变成评估对象

五级评估，每级用适合该级的证据：

1. **假设质量**：8 轴画像——importance / novelty / grounding / falsifiability / data resolvability / feasibility / alternative explanations / actionability；
2. **修订价值**：相对真实前驱，区分实质进展/必要修复/重复/证据不足（分数变化单独记录，不混入判断）；
3. **发展路径**：证据获取、连贯修订、科学连续性、继续/停止决策；
4. **研究 run**：整个图的探索广度与深度、跨分支综合、预算分配（**直接评估，不由路径分平均得到**）；
5. **科学贡献族**：按科学问题分组，记录新增了什么（新区分/有信息的负结果/被支持的发现/不确定性缩减），并区分"提出的想法"与"被完成调查支持的贡献"。

对标表（Table 1）显示：AgentIdeaBench/DiscoveryBench/BLADE/ScienceAgentBench 都只覆盖单点，只有 OEB 部分覆盖过程，**DFM-Bench 是第一个把五级全部做成显式评估对象的**。

## 4. 结果怎么读（五个 RQ）

### RQ1 假设质量：4.86 → 5.18 → 5.39（两轮 RSI）

细看各轴（0–10 分制，AI 评委 GPT-5.6 Sol）：

| 轴 | R0 | R2 | 变化 |
|---|---|---|---|
| Falsifiability | 4.00 | 6.20 | **+2.20（最大）** |
| Alternative explanations | 4.44 | 5.98 | +1.54 |
| Data resolvability | 3.73 | 4.99 | +1.26 |
| Feasibility | 4.79 | 5.87 | +1.08 |
| Grounding | 4.24 | 4.56 | +0.32 |
| Actionability | 5.20 | 5.47 | +0.27 |
| **Importance** | **6.48** | **6.04** | **−0.44（下滑！）** |
| **Novelty** | **4.87** | **4.58** | **−0.29（下滑！）** |

**关键读法**：增益全部集中在"把调查做扎实"（可证伪、备择解释、数据可解），而 importance 和 novelty **双双下滑**。第二轮增益（+0.21）已小于第一轮（+0.32）。

### RQ2 行为变化：exploitation 收缩

evolve+repair 占比 77.5% → 91.7%；restart 21.7% → 5.0%（episode 11–20 处从 ~32% 崩到 3%）。发展路径分提升最大的是"证据与推理纪律"（+1.25），**"学科连接"反而下降 0.28**，探索和预算分配几乎没改善。

### RQ3 人类评审（27 名医学/生物背景评审，292 份匿名提案，盲评）

- 每步修订平均分变化：**DiscoveryRSI-27B +0.07** vs GPT-5.6 Sol +0.03 vs **GPT-6 Luna −0.01**；
- 修订结果分布：41% 改善 / 47% 持平 / 12% 变差（Luna 是 25%/44%/31%）；
- 但绝对分是混合画像：importance（3.10 vs 2.94）和 evidence-bounded claims 上赢 GPT-6 Luna，**data fit、备择解释、信息量三项反而输**。

### RQ4 Inspiration rate（本论文最有趣的评测）

定义：生成的假设版本与"模型截止日期之后发表的文献"存在具体连接（后续论文提供了相关实验设计/对照/测量/可检验空白）的比例。

- **DiscoveryRSI-27B：6.3%（74/1176）**；DeepSeek 5.4%；GLM 2.8%；GPT 2.5%；Claude 2.3%；
- 分域：therapeutic targets 高达 **16.9%**，clinical & population health 仅 2.3%；
- 语料构建：420 次引文双向遍历 → 17,790 条引文边、16,440 篇解析出版物，按各组模型截止日期过滤。

**必须读他们对自己方法的批评（7.4 节末）**：Claude 低分可能主要是**检索门控假象**——Claude 的提案中位数 41,134 字符，而检索只取前 6,000 字符（出处/修订说明把科学内容挤出了评估片段）；仅 11.5% 的 Claude 提案通过检索门，通过者的阳性判断率（20.0%）与 DiscoveryRSI（20.8%）几乎一样。改用标题做查询的诊断中，Claude 通过率 15→95。**结论：6.3% vs 2.5% 的差距部分真实、部分是格式伪影，团队自己承认"需要前瞻性追踪来确认研究者是否真的采纳这些假设"。**

### RQ5 迁移：电池域（4 任务，200 episodes，351 假设）

同一套 Lead–Generation–Evolution–Critique–Compiler 循环原样跑通，假设质量 5.61、实质进展率 58.47%。说明框架与领域弱耦合。

### 训练细节（容易忽略但重要）

- 底座 Qwen3.8-27B，全参数微调，256K 上下文；
- 15,792 条研究轨迹 → 经过归属/过滤/分词后**只剩 2,397 条训练轨迹**（634 Lead / 861 Generation / 902 Evolution）；
- 2.91 亿 token 中**只有 618 万（2.12%）受到直接监督**——绝大部分经验只做上下文不做梯度。这个"监督率"是理解 credit 方法稀疏性的关键数字。

## 5. 值得抄的 5 个设计

1. **H=(c,π,d,a) 四元组直接抄进系统 prompt 和数据 schema**——尤其 d（预写判定标准）和 a（预写备择解释），两者是防事后合理化的结构化手段。
2. **执行契约与科学评估分离**（Harbor 的设计原则）——工程验收和科学判断用不同的裁判、不同的证据。
3. **TrueSkill 处理盲评偏好**，而非要绝对分——评委噪声大时，成对比较+不确定性建模比 1-10 打分稳健得多。
4. **Credit 三原则**：上限截断（W_max）、血缘不加分、无支持不分配——直接回应多智能体 credit assignment 这个老难题（对照 MAST 的"验证 21%"失败模式）。
5. **Dev/test 家族分离 + 四种更新组合分别验收**——递归自我改进不污染评测的最低保障。

## 6. 三个坑（论文自己暴露的）

1. **exploitation 收缩**：RSI 让系统越来越会"修"，越来越不敢"开"（restart 21.7%→5%，importance/novelty 双降）。自改进系统需要显式的探索预算或多样性正则——这正是调研报告 11.3 说的"per-idea 评分看不见总体塌缩"的活体案例。
2. **格式影响评测**：41k 字符提案被截到 6k 导致检索门挂掉（Claude 案例）。任何"文献对答案"式评测都要先做格式敏感性诊断。
3. **监督率仅 2.12%**：15,792 条轨迹最后只有 2,397 条可用——经验→训练信号的转换损耗是这类方法真正的成本中心。

## 8. 对我们项目的三个直接行动

1. **最小复刻（一两周量级）**：一个领域（如 MIMIC-IV 公开子集或你们自己的数据）+ H 四元组 schema + Blinded Critique/TrueSkill + evolve/repair/restart 三操作 + DFM 五级评估。**可以先不做模型训练（跳过 ①），只做 harness replay（②）**——论文自己说明模型冻结时 harness replay 也能独立产生改进。
2. **把 exploration 塌缩做成研究点**：论文暴露了 restart 率崩塌但没有解决。加一个组合层面的多样性约束（如跨 family 的 restart 配额）然后测 quality-diversity 前沿——这是一个直接的、可发表的增量。
3. **评测协议直接以 DFM-Bench 五级为模板**，再加上我们 11.5 的"回溯对答案"数据集设计——两者拼起来就是完整的评测故事。
