## 3. ② 假设生成与门控

| 项 | 内容 |
|---|---|
| 输入 | `hypotheses/drafts.json`：5 条四元组 **+ 1 条故意注入的伪造引文假设**（`H-FAKE`，用于测门控） |
| 每条结构 | `hid / branch / claim / plan{data,method,cost_estimate} / decision_criteria[{metric,direction,threshold,min_frac,supports,weakens}] / alternatives[] / citations[{cite_id,quote}]` |
| 门控规则 | ① `bucket` 与 `directions` 白名单；② 引文必须在已入库原文里**逐字命中**（对 `norm_quote` 做规范化比对）；③ 每条至少 2 个备择解释 |
| 输出 | `hypotheses` 表 **7 行**（pass 6 / reject 1）；`hypotheses/H-*.json` 7 个文件；`verdicts/` 后续写入 |
| 拒绝样例 | `H-FAKE`：`citation[0] REJECTED: quote not found in stored abstract/fulltext` |
| 事件 | `gate` × 7 |
| 成本 | 0（无模型调用；假设由 Boss 起草，本轮未做 Elo 盲评） |

**四条可解释假设 + 一条精度假设的实际输入字段**（以 H-I1 为例）：

```
claim            在多数流域（≥60%），年径流对年降水的弹性大于 1…
plan.method      年度 log Q ~ log P 的 OLS 斜率；跨流域统计弹性>1 的比例
decision_criteria[{metric: elasticity, direction: ">", threshold: 1.0, min_frac: 0.6}]
alternatives[]   2 条（伪回归 / 格点降水低估山地降水）
citations[]      doi:10.5167/uzh-204382（逐字句）+ arxiv:1911.07249v3
```

## 8. 可复现链（一行一锚点）

```
papers.raw_sha256 ──► claims(char_start,char_end) ──► hypotheses.gate_status
                                                          │
artifacts/data/DATA_SHA ──► evaluations.code_sha ─────────┘
                                                          │
                          verdicts/*.json ──► anomalies ──► observation_round2.md
```

任何数字都能反查到：哪份数据（DATA_SHA）→ 哪份代码（code_sha）→ 哪条假设（hid）→ 哪条判定规则（direction/threshold）。

## 9. 台账口径（必须写清，否则数字会被误读）

- `costs` 是**追加式日志**：`experiment/evals` 累计 **117** = 3 次进化尝试 × 39；`evaluations` 表 **78 行** = 2 次 × 39（第一次尝试早于台账补丁）。
- 因此"39 次评估"指**单次运行**的值，不是全 run 累计。要区分必须按 `created_at` 窗口或后续加 `attempt` 字段。
- `events` 同理：`signatures` 3 条说明 analyze 跑过 3 次，只有最后一份 `anomalies.json` 是当前有效版本。

## 10. 本轮修掉的两个缺陷

| 缺陷 | 表现 | 处置 |
|---|---|---|
| **holdout 泄漏** | `best_overall` 按 `test` 中位数挑选，等于用测试集做模型选择 | 改为按 `val` 挑选（并列取特征更少者）；旧结果存档 `summary.v0.1_test_leaked.json`；本 run 数字未变 |
| **异常表重复插入** | `analyze` 每次无条件 INSERT，21 行仅 9 个唯一 `(basin,metric)` | 去重 + `UNIQUE(basin,metric)` + `ON CONFLICT DO UPDATE`（保留 `promoted`）；重跑验证仍 9 行 |
