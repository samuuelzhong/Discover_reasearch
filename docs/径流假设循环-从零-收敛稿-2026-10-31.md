### 0.2 网络检索（2024–2026 前沿）

- 主流基准：LSTM 系在 CAMELS 中位 NSE 0.72–0.765；可微 δHBV 0.72–0.75；Google 全球洪水 AI 在无资料流域 2 年一遇事件 5 天预见期 ≈ 物理模型当日预报（Nearing 2024, Nature 627:559）。
- **架构替换的边际收益只有 ±0.02 NSE**（SSM、EA-LSTM、MC-LSTM 互相印证），且各架构互有失守区间——NSE/低流偏差/峰体积偏差像跷跷板，单目标已撞墙。
- 公认短板（有文献）：①LSTM 存在理论外推上限（73 mm/d，低于训练范围 183 mm/d，对极端降水呈凹性响应，HESS 29:5871）；②确定性 LSTM 系统性低估 97% 的 top 0.05% 极端流量（HESS 30:6339）；③受调控流域 LSTM NSE 低至 0.39（Mangukiya 2025, WRR），强管理水库全模型失效（Hydra-LSTM 预印本）；④全球模型在美国反而输给区域模型（EGUsphere 2025-769）；⑤不确定性量化是最大缺口（Phil. Trans. R. Soc. A 2025）。
- 已被占住的位置：GraphRiverCast（河网基础模型）、StefaLand（全球 Caravan 陆面）、卫星嵌入替代静态属性（Ou 2026 GRL）、MCR-LSTM（放松版守恒，2025）、多源水量闭合框架 PHPM-MDCF（HESS 29:627）、印度水库加剧径流骤旱（2024）。
- 威胁侧：全球径流连续萎缩（WMO 2023–2025 连年报枯）、74% 区域向骤旱转变（Yuan 2023, Science）、洪水威胁 186 万亿美元资产/40 亿人（Kang 2025, WRR）、水文鞭击（wet-dry 快速切换）已有加州专门研究（2026）。

### 第 3 轮 R3：精炼、合并、对抗性攻击

对抗性攻击记录（对每个存活假设问"什么证据会杀死它"）：

- 攻击 S1（尾形控制外推上限）："会不会只是降水极端没见够？" 反驳：73 mm/d 上限**低于**训练范围 183 mm/d，排除单纯未见极端降水；凹性响应是结构性饱和，不是数据稀疏。残余风险：上限可能部分来自损失函数（均方误差压峰值）→ 裁决实验必须包含损失对照臂。
- 攻击 S2（人类决策低维可逆）："调度决策受市场、政策、人为差错影响，可能高维不可逆。" 裁决设计：用有公开调度记录的美国水库做恢复精度上限测试——若需分段规则数远超典型 operating rule（分段目标水位+hedging 系数），假设被否证。
- 攻击 T1（蓄水博弈同步化）："放水相关性升高可能只是同期气候强迫相关（同一场旱）。" 裁决：扣除气候共变因子（降水/蒸散发联合距平）后的**偏相关**才是人类决策信号。
- 攻击 T2（偏差债）："设计规范用的频率分析不依赖 ML 模型。" 限定：主张只覆盖**模型辅助频率分析**的那部分实践（工程影响评价、未来情景设计洪水），且可量化为"设计值 vs 事后实测极值的比率历史"。

### 收敛判定

继续生成更好假设所需的全部关键量，都属于**只有实验/数据才能回答**的类型：
1. 尾形参数 vs 峰值偏差的跨流域相关——需要合成流域+再分析实验；
2. SWOT 蓄水量反演放水序列的可行精度——需要真实水库对照；
3. 扣除气候共变后的调度相关升高幅度——需要卫星时序数据实验；
4. 纯新架构/基础模型路线——已被文献证据排除为边际路线，不需再假设。

→ 循环终止，无法在实验前提出更好的假设。

## 2. 最终假设体系

### 总假设（主叙事）

**径流模拟的天花板不在网络架构，而在三块被当作噪声丢弃的系统性过程：极端事件的产流机制切换（S1）、不可观测的人类调度决策（S2）、质量出口的观测缺失（S3）。把这三者变成模型的显式状态/结构约束，就能同时打破 NSE–低流–峰体积的跷跷板，并直接产出两个此前未被发现的人类威胁（T1、T2）。**

### S1 性能假设：极端外推上限由蓄水容量分布的尾形控制

- 主张：LSTM 对极端降水响应的凹性饱和（上限 73 mm/d），对应其学到的"降水→径流"映射里缺少**产流机制切换**——真实流域在特大暴雨时主导机制从"蓄满产流"（土壤蓄满后雨水才变径流）切换为"超渗产流"（雨强超过入渗能力直接产流）+ 坡面连通（坡面水流接通后快速汇流）。把流域蓄水容量做成可学习的分布（尾形参数化：形状 β + 最大容量），响应曲线尾段由分布尾形显式决定，上限消失。
- 可阐述的物理认知：①全流域"蓄水容量分布尾形图谱"（哪里是薄尾=极易超渗，哪里厚尾=蓄满主导）；②S4D 特征值谱提供各流域汇流时间常数诊断，与尾形交叉验证产流/汇流分工。
- 可证伪预测：跨流域看，峰值低估幅度应与拟合的容量分布尾参数显著相关（Spearman 相关）；在合成流域（真实产流机制已知）上，容量分布模型应恢复真值机制而 LSTM 复现凹性。
- 裁决实验：合成流域（机制已知）因果裁决 + 531 流域分层评估（含损失函数对照臂）。

### S2 性能+认知假设：人类调度是低维可逆的决策结构，不是噪声

- 主张：受调控流域的性能崩塌（NSE 0.39）不是"随机干扰"，而是模型没拿到**调度决策这个隐状态**。用 SWOT 卫星水面高程（2022 年底发射，全球免费观测河流湖库水位）+ 水量平衡方程反演放水序列，无监督恢复调度规则（分段目标水位 + hedging 系数的低维结构），受调控流域性能应大幅回升。
- 可阐述的物理认知：全球首张"调度规则图谱"——每座水库的 hedging 倾向、蓄水目标、对干旱的敏感度，且可检验"规则漂移"（干旱年份调度行为系统性改变）。
- 可证伪预测：反演放水序列与公开调度记录的相关性应显著高于"仅靠径流残差学惯性"的基线；规则维度应收敛到低维（若需 >8 段分段规则则假设被否证）。
- 裁决实验：美国有公开调度记录的水库做恢复精度上限测试。

### S3 认知假设：水量闭合残差是"缺失过程探测器"

- 主张：守恒约束下的闭合残差（进水 − 出水 − 储水变化 ≠ 0 的部分）不是误差，而是**信号**：它在空间/时间上的集中点标记了未建模过程（灌溉取水、岩溶渗漏、冰川融水、跨流域调水）。
- 证据链：MC-LSTM 无雪数据仍反演出雪水当量 r≥0.91——说明守恒隐状态携带真实物理；RiverMamba 实测大跌正是未建模过程的指纹。
- 裁决实验：在已知有灌溉/调水的流域，检验残差热点与实际取水位置的重合度。

### T1 新威胁：干旱下的"蓄水博弈同步化"→ 供水组合假象

- 机制链：S2 确认调度可反演后 → 检验全球水库放水的跨流域相关性：干旱年份相关性升高，若在扣除降水/蒸散发气候共变（同一场旱的影响）后的偏相关仍然显著升高，即证明是人类**独立理性决策**（各自留水过冬）造成的同步——多个供水水源"同时"失效，所谓水源多元化组合在系统旱年里是假象。
- 与先行工作的差异：印度研究（2024）证明单流域内水库加剧径流骤旱；本假设首次提出**跨流域、决策层面的同步化机制**。
- 裁决实验：SWOT/水位卫星时序 + 偏相关分析。

### T2 新威胁：模型偏差债 → 防洪基础设施的系统性欠设计

- 机制链：S1 证实外推上限是结构性的 → 则所有依赖"模型辅助频率分析"的设计洪水（工程影响评价、气候变化情景下的设计值）继承了系统性低估 → 用 1980 年代以来"设计值 vs 事后实测极值比率"的历史序列可量化这笔越滚越大的债，且复利随气候变化放大。
- 与先行工作的差异：峰值低估已知是模拟问题（2023），从未被表述为**工程欠设计的系统性风险**。
- 裁决实验：设计值-实测极值比率历史 + 用 S1 修正模型重算设计洪水的敏感性。

### T3 附属预测（S1 的气候后果，并入不单列）

- 变暖使降水强度分布右移 → 流域更频繁触碰容量分布尾形区 → 模型技巧衰减速率可测：按变暖时片切片，技巧衰减应集中在尾参数临界附近的流域。这同时把 S1 与气候变化直接挂钩，服务"径流变化对人类的新威胁"叙事。

## 4. 一页人话版

现有主流径流模型像三个"偏科生"：平时成绩（NSE）都刷到 0.75 附近换不动了，换什么架构都只差 0.02——因为大家卡住的地方根本不是网络结构。真正的病根有三处：

1. **大暴雨没见过世面**：模型对特大暴雨的响应像被掐住的水管（上限 73 毫米/天，比训练数据里的 183 还低），因为它没学过"土壤喝饱之后雨会直接流走"这个机制切换。我们把流域土壤的"胃口分布"（哪里容易喝饱、哪里永远喝不饱）做成模型结构，上限就能打破——顺带画出全球第一张"流域胃口分布图"。
2. **水库大坝装聋作哑**：有人管水的流域，模型成绩跌到 0.39，因为调度员的决策模型根本看不见。SWOT 卫星（测水面高程的新卫星）+ 水账反演能把调度规则猜回来——顺带发现威胁一：大旱之年全世界的调度员不约而同"存水过冬"，多路水源同时掉链子，靠"东边不亮西边亮"设计供水的人会被打脸。
3. **水账对不上的地方就是没建模的过程**：守恒约束下水账的差额不是误差，是线索——差额集中在哪，哪就有我们不知道的取水、渗漏、调水。顺带发现威胁二：既然所有模型都系统性低估特大洪水，那么拿模型算出来的"设计洪水"去修的堤坝、水库，天生就偏矮——这笔"偏差债"随气候变化越滚越大。

循环到此收敛：四个关键未知量（尾形-峰值相关、SWOT 反演精度、偏相关升高幅度、修正后设计值敏感度）只能靠实验回答，假设阶段结束。
