## 2. 这一圈实际跑出来的数字

**数据**：24 个真实 USGS 流量站（ME/NC/CO/WA，面积 80–2500 mi²，覆盖率 ≥85%），1990-01-01–2022-12-31；
强迫来自 NASA POWER（PRECTOTCORR/PRECSNO/T2M/T2M_MAX/T2M_MIN），PET 用 Hargreaves。
数据包哈希 `bc59d1317da7`，每流域 CSV 可复查。

**① 文献层**：入库 **24** 篇（arXiv 9、DataCite 12、本地 PDF 3），逐字校验通过的引文 **18** 条。

**② 假设层**：提交 7 条，门控通过 6 条、拒绝 1 条（伪造引文 `H-FAKE`，拒绝原因写进报告表格）。

**③ 分支1（精度）**：

| | seed 基线 | 进化后 |
|---|---|---|
| val NSE（中位） | 0.3405 | **0.4305** |
| test NSE（中位） | 0.3766 | **0.4601** |
| test KGE（中位） | — | 0.4669 |

39 次评估、3 代、3 岛；最佳设计 7 个特征（`p_lag1 + log_p_ewm + t_ewm + 谐波2 + pet_roll90 + deficit`）。
RSI 证据：算子策略从均权演化为 **add 0.86**、swap 0.56、remove/tweak 0.42——搜索策略本身在被改进，
复跑同 seed 结果完全一致（0.4305/0.4601/0.4669）。

**④ 分支2（可解释）**：

| 假设 | 预注册判据 | 实测 | 判决 |
|---|---|---|---|
| H-I1 弹性>1 | ≥60% 流域弹性>1 | 76.2%（n=21） | **supports** |
| H-I2b 融雪质心前移更快 | 组间差 ≥0.2 d/yr | 融雪 +0.348 vs 非融雪 −0.335，差 **0.682**（13 vs 8） | **supports** |
| H-I3 越干旱径流比降得越快 | r < −0.2 | r = **+0.199** | **weakens**（符号相反，值得追） |
| H-I4 后半段弹性更低 | Δ 中位数 < 0 | Δ = **−0.197** | **supports** |
| H-A1 雪储只在融雪区有用 | 组间差 ≥0.01 | 0.0108 vs 0.0025，差 **0.0082** | **weakens**（方向对、效应量不够） |

**异常通道**：6 条 |z|≥2.5 的跨流域离群，例如 `usgs-09171100` 的 Δ弹性 = −4.35（同类型中位 +0.12，z=−4.8）、
`usgs-12449950` 的径流比趋势 z=+5.2。已提升 4 条为第 2 轮观察（`analysis/observation_round2.md`）。
检测器在"已知注入 shift"的合成数据上：recall 1.0、precision 0.6——宁可多问几个问题。

**成本**：39 次模型评估、8 次 API 检索、约 217 页 PDF 解析；全程无 LLM API 花费（判决全靠统计与执行）。

## 3. 三条"这是真的"的证据

1. **反幻觉可复现**：伪造引文的假设被门控拒绝，拒绝原因与时间戳都在 `state.db`。
   报告里每一条引文都能在 `claims` 表里找到原文位置（char_start/char_end）。
2. **数字可复算**：`data_sha` + `code_sha` + 固定 seed，重跑得同一组 NSE。
3. **结论允许失败**：5 条假设里 2 条被判弱/反向，原样写进报告；`H-I2` 因分组后 rain 组只剩 1 个流域被判"不可判"，
   修正过程作为 amendment 记录在 `decisions` 表，而不是悄悄删掉。

## 5. 已知缺口（下一步就按这个顺序做）

1. **Elo 盲评没做**：5 条假设由我一次写就，没有 pairwise 对比，所以排行榜是空的。下一轮应先生成 5–8 条同类假设再两两比。
2. **假设仍由 Boss 撰写**：系统还没自主出题（与调研第十一章一致）。可先用异常通道的 12 条问题做种子。
3. **强迫是格点不是面平均**：换官方 CAMELS 即可消除这一条；`camels_local` 适配器已就绪。
4. **模型族偏弱**：线性+特征工程 NSE≈0.46，LSTM/Transformer 基线（torch 已装）应补上，否则"精度"分支缺乏竞争力。
5. **异常通道缺对照设计**：目前是跨流域 robust z；下一步加"同流域前后期 + 属性回归"，把解释力提一档。
6. **单域验证**：框架与域解耦尚未被证明，值得用材料/序列设计跑一次最小闭环。
