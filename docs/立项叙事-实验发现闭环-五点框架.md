# 立项叙事：一个能被证伪的自动科研闭环

**版本** v1.0 ｜ 2026-10-27 ｜ 对应实现：`discovery_loop/`，实跑 run `hydro-r1`

> 写法约定：全文按「出发点 → 难点 → 参考点 → 创新点 → 落脚点」组织。每一条创新点都指到代码位置或实跑数字，落脚点的每一条结果都回指前面提出的难点。凡未做到的，在文末单列，不用"未来工作"糊过去。

## 一、出发点：锚定什么领域，解决什么问题

### 1.1 领域选择不是偏好，是被验证器决定的

过去两年，AI for Science 最响的声音都集中在一类地方：能自动产出论文的系统（AI Scientist、Robin、Co-Scientist），和能自动改进代码的系统（AlphaEvolve、Darwin Gödel Machine、ShinkaEvolve）。这两类之间有一条清晰的分界线——**验证一次要多少钱、要多久**。

- 代码域的验证器满足 Jason Wei 所列五个条件（客观真值、快、可扩展、低噪声、连续奖励）的全部，所以 RSI 在那里真的跑起来了；
- 湿实验域的闭环成本是 $1–3/候选、1–2 周一轮（Google 适配体工作的公开数字），绝大多数团队跑不起，所以那里的"闭环"大多停在示意图；
- 论文域没有裁判，于是只能用 LLM 评委代替，而 LLM 评委与生成器同源。

**径流模拟恰好落在中间那条缝里。** 它有：

| 条件 | 水文的情况 |
|---|---|
| 客观真值 | USGS 实测日均径流（00060），公开、免费、逐日 |
| 快 | 一次完整评估（24 流域 × 33 年）在笔记本上 < 10 秒 |
| 可扩展 | 候选是特征设计方案，不是仪器参数 |
| 低噪声 | NSE/KGE 是领域四十年标准指标，可比 |
| 领域成熟度 | CAMELS/CARAVAN 基准、物理模型、签名统计方法齐备 |
| 两条真分支 | 提高精度（可判定）；挖掘变化（可判决，但需要预注册） |

所以锚定的问题很具体：

> **在一个"实验是计算、真值是实测、指标是标准"的领域里，能不能让机器完整跑完「观察 → 假设 → 实验 → 判决 → 新问题」这一圈，并且每一圈都可复现、可审计、可反驳？**

这个问题不是"AI 能不能做科学"的宏大版本，而是它的一个可执行切片。切片的选择本身就是方法论的表达：**先找一个裁判可靠的域，再谈自动化。**

### 1.2 不做的事

明确不做三件：不做通用 AI 科学家（红海、不可验证）；不做湿实验（成本与周期不可控）；不把"提出有价值的问题"作为系统目标（无基准、验证延迟以年计，评审会第一时间挑战）。这三条排除把一个宏大命题压成了一个学期内能出数据的问题。

## 二、难点：为什么重要，为什么还没解决，阻力在哪

### 2.1 为什么重要

如果这条路能走通，它的意义不在于多发现一条水文规律，而在于**证明"自动科研"可以在裁判可靠的域里做成闭环**，从而给不可靠域提供一个可迁移的模板：先把真值工程做好，再谈智能。

### 2.2 四层阻力（每一层都有对应的失败案例）

**阻力一：裁判问题——"什么算好"判不准。**
价值可以拆成可证伪性、可行性、信息价值、新颖性、重要性五个组件；前三个能机械判，第四个只能用有偏代理，第五个本质不可判（双重反事实）。现有系统全部栽在这里：AI Scientist 用 LLM 评审，DiscoveryRSI 用 LLM 盲评，Co-Scientist 用 Elo 锦标赛——Elo 排出的是"评委偏好序"，不是"真值序"。

**阻力二：幻觉问题——上游不真，下游全废。**
文献层一旦混入模型记忆，整条链就是精致的小说。这不是概率问题，是结构问题：只要"引用"这个动作没有校验，模型就有动机编造最顺滑的那句话。

**阻力三：闭环退化——跑得越久，越只会解题。**
这是最隐蔽的一层。所有"假设池 + 精化"的系统，稳态都是不断打磨池子里已有的东西。DiscoveryRSI 自己的数据就是活体证据：质量总分 4.86→5.39，但增益全在 falsifiability（+2.20）和备择解释（+1.54），**importance（6.48→6.04）和 novelty（4.87→4.58）双双下滑**，restart 率 21.7%→5%。系统学会了"把调查做扎实"，同时越来越不敢开新问题。

机制上说清楚为什么：出题的价值验证延迟以年计；所有新颖性评分都是 per-idea 的，而同质化是定义在提案**联合分布**上的性质——评分体系看不见自己要惩罚的东西。

**阻力四：成本与真实性——便宜的没闭环，闭环的不便宜。**
湿实验闭环有 dollar/candidate 级数据但没人跑得起；RSI 论文有机制没真实数据。两头都缺的是：**有真实观测、有硬指标、还跑得起的闭环**。

## 三、参考点：已有什么技术，各自局限在哪

| 技术线 | 代表 | 解决了什么 | 在本题上的局限 |
|---|---|---|---|
| 文献工具化 | PaperQA2、Paper2Agent | 论文变成可调用工具；LitQA2 85.2% 超博士 73.8%；100 篇中 74 篇成功 agent 化 | 只做检索与复算，不产生假设，也不判决。且工具化只是换容器装幻觉——论文自带的 bug 一起继承 |
| 假设结构化 | DiscoveryRSI | H=(c,π,d,a) 四元组，判定标准先于结果；DFM-Bench 五级评估 | 裁判仍是 LLM 盲评；无真实实验闭环；importance/novelty 反向下滑 |
| 端到端产论文 | AI Scientist、Robin、Co-Scientist | 从想法到稿件全自动 | 产出物是论文，不是被验证的知识；评审环节是橡皮图章（MAST 已量化：被测框架失败率 41%–86.7%） |
| 进化搜索 | FunSearch、AlphaEvolve、ShinkaEvolve | 在强验证器下拿到公认硬结果（48 次矩阵乘法、Borg 0.7% 算力回收） | 只优化一个标量指标，不问"为什么"；不产生可解释命题 |
| 水文领域方法 | CAMELS 基准、LSTM 大军、签名/趋势统计（Theil–Sen、Mann–Kendall、流量质心） | 指标、签名、趋势检验全部成熟可信 | **从未被接进一个自动闭环**；文献里的假设从来是人事先想好的，机器只负责跑 |
| 多智能体框架 | Anthropic 编排-执行、Cognition 单线程写入 | 并行读取 + 串行写入成为工程共识 | 收益主要来自 token 预算（BrowseComp 上仅 token 用量解释 80% 方差），不是角色扮演 |

**一句话概括参考点的集体空缺：上游不可信、中游无裁判、下游不闭环、回路缺异常。**

四条里前三条已有单点方案，第四条基本空白——这决定了创新点的排序。

## 四、创新点：和现有技术不同的四处

### 创新点 1（核心）：把裁判从模型换成领域原生真值

不是"更好的 LLM 评委"，而是**取消 LLM 的裁判身份**。

- **分支 1（精度）**：候选是特征设计方案，引擎持有 y 和拟合；系数与标准化参数**只在 train 段拟合**，val 用于选优，test 只报告。候选永远看不到 Q。
- **分支 2（可解释）**：裁判是预注册的判定算子（`>`, `<`, `abs>`, `median>`, `group>`, `corr<`），输入是 21 个流域的水文签名表，阈值在跑数据前写死入库。

LLM 只保留两个角色：起草假设、执行结构门控。它**不判断假设好坏**——价值的裁判是数据。

代码位置：`experiment.py::evaluate_code`（时空外推 + 岭回归）、`analysis.py::hypothesis_test`（六个判定算子）。

### 创新点 2：反幻觉做成结构，不做成提示词

四道闸门，全部可机器验证：

1. `papers` 表每条记录存 **URL + 检索时间 + 原文 SHA256**；
2. 引文必须在本 run 抓到的原文里**逐字命中**（`scout.verify`）；
3. 门控机械拒绝不可证引文——实测把一条伪造的"多智能体自动发现物理定律"引文拦在门外，`gate_status=reject`；
4. 论文 MCP 服务器返回**带字符偏移的原文句子**和三档判定（supported / partial / no_support_found），找不到就明确要求"不许引用"。

关键点在于：这不是"让模型更诚实"，是**让编造在结构上无法通过**。

代码位置：`core.py`（存储与校验）、`hypothesis.py::register`（门控）、`paper_mcp.py`（零依赖 JSON-RPC 服务器）。

### 创新点 3：异常通道——第四条边

现有系统的回路是 ④→②（分析结果喂回假设池），稳态必然收敛到精化既有假设。本框架加一条 **④→①**：

> 对实验数据建统计基线，**偏离基线的观测不经过假设池，直接以"异常报告"形式进入下一轮观察**。

实现是跨流域稳健 z（median/MAD）作用在**变化量**上（Δ弹性、径流比趋势、质心趋势），\|z\|≥2.5 触发。产出物是**问句**，不是结论。

这条通道是"出题"目前唯一成活的形态——它与时域天文异常挖掘、FunSearch 同构：**不是 LLM 学会了提问，而是环境里存在一个便宜且自动的"这不对劲"检测器。**

代码位置：`analysis.py::anomaly_channel` / `calibrate`。

### 创新点 4：可审计的自我修正

科研诚信机制化，不是口号：

- 分组缺陷在**计算任何组间差值之前**改，并写入 `decisions` 表（H-I2 的 rain 组只剩 1 个流域 → 改为 snow/non_snow，理由留档）；
- 判"削弱"的假设**照原样保留**，不改阈值、不改口说"接近显著"；
- 每次评估落 `evaluations` 表并带 code SHA，换 seed 复跑数字一致。

代码位置：`cli.py::cmd_judge`、`boss.py::stage_report`、`decisions`/`evaluations` 两张表。

## 五、落脚点：取得了什么结果，逐条对应前面

### 5.1 对应难点一（裁判）：五条假设全部预注册判决，无一事后重写

| ID | 主张 | 实测 | 判决 |
|---|---|---|---|
| H-I1 | 多数流域弹性 > 1 | 76.2%（16/21） | supports |
| H-I2b | 融雪型质心前移比非融雪快 ≥0.2 d/yr | +0.348 vs −0.335，差 **+0.682** | supports |
| H-I3 | 越干旱，径流比下降越快（r < −0.2） | **r = +0.199**，符号相反 | **weakens** |
| H-I4 | 后半段弹性低于前半段 | Δ 中位 **−0.197** | supports |
| H-A1 | 雪储项只在融雪区提升 NSE（≥0.01） | snow +0.0108 / non_snow +0.0025，差 **0.0082** | **weakens** |
| H-FAKE | （故意注入的伪造引文假设） | 门控拒绝 | **reject** |

三条支持、两条削弱、一条被拒。削弱的两条不是失败，是**裁判有效的证据**——如果所有假设都通过，说明阈值定松了或者裁判不可信。

### 5.2 对应难点二（幻觉）：24 篇真实文献入库，伪造引文被拦

数据源走真实 API（arXiv / DataCite 可用；OpenAlex / Crossref / Semantic Scholar 在本网络被 429 限流，失败写进事件日志，**不静默补脑**）。三篇本地 PDF 已工具化为 MCP，`check_claim` 返回带偏移的原文句子。

### 5.3 对应难点三（退化）与参考点空缺：异常通道产出下轮观察

- 6 条 \|z\|≥2.5 异常（典型：`usgs-09171100` Δ弹性 −4.346，同类中位 +0.12，z≈−4.8）；
- 4 条提升为第 2 轮观察，写入 `observation_round2.md`，**不进入假设池**；
- 检测器可校准：在注入已知真值的合成流域上 recall **1.0** / precision **0.6**（precision 不高是刻意的——通道宁可多问几个问题）。

### 5.4 对应参考点（进化搜索）：RSI 在特征空间里真的学到了偏好

- val NSE **0.3405 → 0.4305**，test **0.3766 → 0.4601**，KGE 0.467（39 次评估，单次 0.09–0.20 s）；
- **基线口径说明**：0.3405 用的是 `p_ewm(0.05)+harm(1)`（H-A1 的对照设计，比引擎自身种子更强）；引擎 island0 的种子是 `p_ewm(0.1)+harm(1)`，val 0.3118 / test 0.3578。所以真实增益区间是 **val +0.090 ~ +0.119、test +0.084 ~ +0.102**，取保守值对外报。
- 涨点归因（留一法）：`pet_roll(w=90)` −0.178、`harm(k=2)` −0.068、`deficit` −0.050、`p_lag` −0.026、`log_p_ewm` −0.022、`t_ewm` **+0.001（冗余）**。即胜出设计靠的是**PET 的长期记忆 + 累积亏缺 + 季节谐波**，不是"更多降水记忆"。
- 换 seed 复跑，数字完全一致（评估可复现）；
- 算子权重由 0.5 演化到 **add 0.86 / swap 0.56 / remove·tweak 0.42**——方向符合"先长特征再精修"，但 39 次评估下这个信号噪声很大，只能算方向性证据，不能算 RSI 生效的证明（见 6.7）。

### 5.5 一句话收束

> **不是造一个更聪明的 agent，是造一条每个结论都必须被执行和证伪的流水线。**

技术赌注押在**验证器工程 + 裁判可靠性 + 成本-质量前沿曲线**，不押在更复杂的 agent 拓扑。

## 六、没做到的（与落脚点同等重要）

1. **Elo 盲评未做**：5+1 条假设是一次写成的，没有 pairwise 比较，所以"假设质量"这一维度尚无数据。
2. **假设仍由 Boss 撰写**：系统还没有自主出题，异常通道只提供了 12 条问题种子。这是最大的空缺，也是下一轮的主攻方向。
3. **无 LSTM 基线**：精度分支当前只有岭回归 + 特征工程，竞争力不足以对水文社区发声。
4. **强迫是格点不是面平均**：NASA POWER 0.5°×0.625° 格点，PET 为 Hargreaves 估算，山区流域有系统偏差；官方 CAMELS 适配器（`data --source local`）已就绪未启用。
5. **异常通道缺对照设计**：目前只有跨流域横截面 z，没有"同流域前后期 + 属性回归"的双重差分，容易把站点迁移/取用水变化误判为气候信号。
6. **H-A1 的对照组不够干净**：线性模型下雪储项在非融雪区输入近零，需要置换检验或分区交叉验证外推才硬。
7. **v0.1 存在一次 holdout 泄漏（已修）**：`best_overall` 原按 test 中位数挑选，等于用测试集做模型选择。现已改为按 val 中位数挑选（并列时取特征更少者），旧结果存档 `summary.v0.1_test_leaked.json`。本 run 中 val 最优恰好也是 test 最优，故数字未变，但**程序上必须修**——若换 seed 出现分歧，旧写法会系统性高估。
8. **三岛设计未验证有效**：最终赢家来自 parsimony 岛，另两个岛（均值加权、坏流域惩罚）都没超过它；3 代 × 39 次评估不足以判断岛多样性是否有贡献。这个主张目前只有代码没有证据。
